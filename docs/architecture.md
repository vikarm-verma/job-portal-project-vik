# Architecture Overview

This project follows a modular full-stack architecture:

- Frontend: React
- Backend: Spring Boot
- Database: MySQL
- Auth: JWT
- APIs: REST

## Components

### Frontend
- Public pages: home, search, details, login, signup
- Protected pages: profile, application, recruiter dashboard
- Shared components and service layer

### Backend
- Authentication and authorization
- User profiles
- Job management
- Application processing
- Resume upload handling

### Database
- MySQL store for users, jobs, resumes, and applications

## Notes

This is a starter structure intended for future implementation.
